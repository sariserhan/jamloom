# Organic discovery and measurement

Jamloom's public guides answer concrete tasks: recording a sound, making a song from favorites, understanding credits and learning DJ transitions. Product pages and guides link to each other and to visible pricing, privacy and availability information. Author attribution identifies Jamloom rather than inventing qualifications or endorsements. Technical checks and musical taste remain distinct.

Google Search Console: the owner confirmed Cloudflare ownership verification and successful submission of https://www.jamloom.com/sitemap.xml on November 9, 2026. This is owner-confirmed evidence. Search coverage, impressions, clicks and queries have not been independently retrieved. Check indexing for the new guide URLs after Google processes the sitemap; submit an indexing request only for a genuinely changed important page. Acceptance is not a ranking or indexing guarantee.

For participating IndexNow search engines, the root verification file and `apps/site/scripts/submit-indexnow.mjs` support post-deployment notifications. Run the script with the changed public paths, for example `node scripts/submit-indexnow.mjs /learn/record-sound-for-ai-song /improvise`. It verifies the live key and requires each URL to appear in the public sitemap before sending it. Do not submit private account URLs or repeatedly resubmit unchanged pages. IndexNow does not replace Google's sitemap.

When publishing a guide, verify the actual workflow and current prices, include useful original instructions, link it from a relevant product page, and use a real modification date. Article/Breadcrumb and product schema describe visible content; they do not invent ratings, reviews, offers or results. Do not create near-duplicate keyword pages. A new content topic should answer a real user question observed in Search Console or support.

Use Search Console for search impressions, clicks, queries, indexed pages and field Core Web Vitals. Existing VisitorPing remains the website analytics source for referrals; no second tracking script was added. Compare useful visits and completed user actions over meaningful periods, not raw bot requests. Traffic and AI referrals have no guaranteed minimum; ongoing measurements are needed before claiming improvement. No external advertising, paid links or unsolicited outreach was started.

Google's AI-search guidance uses the same foundations: accessible pages, helpful original text, clear organization and accurate structured data. No special AI schema or `llms.txt` file is required for inclusion. Sources: [Google AI features](https://developers.google.com/search/docs/appearance/ai-features), [Google technical requirements](https://developers.google.com/search/docs/essentials/technical), [IndexNow protocol](https://www.indexnow.org/documentation).
