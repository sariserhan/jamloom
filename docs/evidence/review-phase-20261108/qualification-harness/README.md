# Archived review-phase harness

These scripts are evidence copies. Their relative imports assume the original ignored `build-review-phase-20261108` directory at repository root. Do not run the copies in this directory. Private environment/account/provider files are deliberately excluded.

The owner-approved permit is finite, one L4, $7.50 maximum over seven days and at most ten $0.75 reservations. `verify-live.mts` claims one preparation and at most one Improvise submit without automatic replay. A failed creation is canceled and capacity is disabled. The independent remote guardian remains responsible for permit/cycle expiry and idle shutdown. Never rerun a claimed paid check blindly.

`submit-apple.mjs` requires successful delivery/privacy/credit/idle evidence and checks the exact existing five-item draft, build 39, credentials and manual release. It uploads final review notes and submits once. Submission does not release the app publicly.

Official references consulted: [Vercel promotion](https://vercel.com/docs/cli/promote), [Apple review submission update](https://developer.apple.com/documentation/appstoreconnectapi/patch-v1-reviewsubmissions-_id_), and the Apple documentation JSON schema for `ReviewSubmissionUpdateRequest.Data.Attributes` (`submitted: boolean`). Context7 was unavailable in this session; official documentation was used.
